# Historical paper-MVP screenshots

The PNG files directly in this directory are earlier local mock/paper-MVP captures retained as historical examples. They show old navigation and legacy workspace/proposal surfaces, synthetic sessions/records and mock market/portfolio values. They are not current hosted screenshots or performance evidence.

Use [the screenshot provenance guide](../screenshots_checklist.md) for authentic fixture sets, dates/context limits and reproduction. Use [the README](../../README.md) for the current six-workspace product and [current status](../current_status.md) for operational acceptance.

The original images remain unchanged. A new public capture must omit private credentials, accounts and sensitive audit identifiers, retain paper/source labels, and record its source commit/date/context.
